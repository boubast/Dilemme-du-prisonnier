# Frontend

Se dossier contient le frontend du projet avec React, TypeScript et shadcn/ui. Il est configuré pour être utilisé avec Vite.

## Installation des dépendances

```bash
npm i
```

## Lancer l'application

Pour lancer l'app en mode développement;

```bash
npm run dev
```

## Ajout des composants

Pour ajouter un nouveau composant shadcn/ui:

```bash
npx shadcn@latest add button
```

Cela placera les composants dans le répoertoire `src/components`
