# Dilemme-du-prisonnier
Créer un environnement d’expérimentation pour le dilemme du prisonnier et pour l’une de ses variantes.

## Docker Compose

Pour lancer l'API backend avec Docker Compose depuis la racine du projet :

```bash
docker compose up
```

Pour l'arrêter:

```bash
docker compose down
```

Une fois le conteneur lancé, la route de santé est disponible ici :

```bash
http://localhost:8000/health
```
